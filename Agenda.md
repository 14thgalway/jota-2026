# Agenda 

The following schedule will be followed on the day

| Time  | Event | Description |
| ----  | ----- | ----------- |
| 9:00  | Radio club setup | The Galway Radio club will setup an antenna for their short wave transmitter and will also have a selection of other gear such as their digital transmitters. They also normally organise sessions to teach morse code and supply “walkie talkies”  |
| 10:00 | Beavers arrival | This is the 6-9 year olds |
| 10:00 | Cubs arrival | This is the 9-12 year olds |
| 12:30 | Campfire | Cubs and beavers | 
| 13:00 | Scouts arrive | These are the 12-15 year olds |
| 15:30 | Campfire | Same format as Cubs + Beavers |


## Small group arrangements 

### Beavers 

Small group arrangement. 

* Group 1: Conference call with another Beaver section from England
* Group 2: Battleship game in carpark (hand signals or shouting)
* Group 4: Treasure hunt
* Group 3: Extra games

Each group will spend 30 minutes at each activity.
Groups will rotate Beavers will be accompanied by Scouter adults and events will be run by Venture Scout volunteers

### Cubs

* Group 1: Chat room sessions at computer laptops. Run by Centripetal volunteers
* Group 2: Radio session + Morse code. Run by Radio club volunteers
* Group 3: Radio orienteering around industrial park
* Group 4: Battleship (Semaphore signals)

Each group will spend 30 minutes at each activity. Cub Scouts will be accompanied by their Scouter adults.
Activities will be run by Venture Scout and Centripetal volunteers.

### Scouts

* Group 1: Chat room sessions at computer laptops. Run by Centripetal volunteers
* Group 2: Radio session + Morse code. Run by Radio club volunteers
* Group 3: Radio orienteering around industrial park
* Group 4: Battleship (Semaphore signals)

Each group will spend 30 minutes at each activity. Cub Scouts will be accompanied by their Scouter adults.
Activities will be run by Venture Scout and Centripetal volunteers.

### Ventures

Ventures will be asked to run some of the above sessions in rotation. They are then free to pariticpate in the activities themselves.
